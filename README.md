# LG 360 Cam Manager Revived (via Web) 

<h3>How to setup</h3> 
*Make sure you have python installed.
<h3>1. Download the repo and unzip it</h3>
<h3>2. run server.py and download ffmpeg if you're prompted to</h3>
<h3>3. Connect your LG 360 Cam to your device using WiFi</h3>
